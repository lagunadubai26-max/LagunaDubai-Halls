# نظام قاعات — لاجونا دبي

نظام متكامل لإدارة قاعات الأفراح: الحجوزات والتقويم، العقود، الباقات، الإضافات، المدفوعات، مصروفات الأفراح، التقارير المالية، وتقييمات العملاء.

## متطلبات التشغيل
1. مشروع Firebase **قيد الإنشاء**: `lagunadubaihalls` (Firestore).
2. تفعيل Firestore + نشر القواعد:
   ```
   firebase login
   firebase init firestore  (اختر المشروع lagunadubaihalls وانسخ الملف firestore.rules)
   firebase deploy --only firestore:rules
   ```
3. بيانات الدخول الأولى (تُنشأ تلقائياً عند أول فتح):
   - البريد: `admin@laguna.com`
   - كلمة المرور: `admin123`
   - ⚠️ غيّرها فوراً من الإعدادات.

## الإعدادات المتوفرة
- **القاعات**: إدارة القاعات وحسابات المدراء (كل قاعة لها بريد/كلمة مرور) — SuperAdmin فقط.
- **الحجوزات**: تقويم شهري، حجز جديد، استعراض لفترة أو سنة كاملة. كل حجز ينشئ عقداً تلقائياً.
- **العقود**: بيانات العقد + الشروط الثابتة (قابلة للتعديل من الإعدادات) + طباعة/PDF.
- **الباقات**: الباقات الأساسية (الأسعار تُدخل من المسؤولين).
- **الإضافات**: أي خدمة خارج الباقة (دبكة سورية، ...).
- **المدفوعات**: العربونات والمدفوعات (نقدي/تحويل).
- **مصروفات الأفراح**: مصروفات كل فرح (مملوك/مؤجر).
- **التقارير**: تقارير مالية لفترة — عدد الأفراح، المحصل، العربون، النقدية، التحويلات، المصروفات، نتيجة التشغيل.
- **التقييمات**: قراءة تقييمات العملاء من نظام تقييمات لاجونا دبي.

## البنية
- `src/` — الموقع (GitHub Pages تلقائي عبر Actions)
- `firestore.rules` — قواعد الأمان (عزل بيانات كل قاعة عبر hallId)
